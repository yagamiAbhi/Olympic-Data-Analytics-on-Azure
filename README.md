# Olympic-Data-Analytics-on-Azure

## Project Summary

* **Data Pipeline:**
    - Source: GitHub
    - Destination: Azure Data Lake Storage (ADLS)
    - Integration Platform: Azure Data Factory (ADF)
* **Data Processing & Analysis:**
    - Platform: Databricks
    - Transformation & Analysis: Databricks Notebooks
    - Transformed Data Storage: ADLS
* **Data Consumption & Analytics:**
    - Source: ADLS
    - Data Storage: Synapse Data Lake Tables
    - Analytics Platform: Synapse SQL
